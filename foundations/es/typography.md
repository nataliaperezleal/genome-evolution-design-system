# Tipografía — Genome Evolution Design System

## Familias tipográficas
- `family/body` → Open Sans (uso general: cuerpo de texto, etiquetas y botones)
- `family/display` → fuente de exhibición (encabezados XL y secciones principales)
- `family/mono` → monoespaciada (código)

## Escala de tamaños
| Token | Valor | Uso típico |
|---|---|---|
| `size/100` | 11px | Etiqueta XS, insignia |
| `size/200` | 12px | Cuerpo XS, botón SM |
| `size/300` (aprox.) | 13px | — |
| `size/14` | 14px | Cuerpo SM, botón MD, activador de acordeón |
| `size/400` | 16px | Cuerpo MD |
| `size/500` | 18px | Título SM |
| `size/600` | 20px | Título MD |
| `size/800` | 24px+ | Encabezado XL |

## Pesos
